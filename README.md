Ai StockSheet(ระบบจัดการสต็อกสินค้าอัจฉริยะ)

เว็บแอปพลิเคชันสำหรับจัดการสต็อกสินค้าแบบครบวงจร ใช้งานง่ายผ่านเบราว์เซอร์ รองรับการสแกนบาร์โค้ดผ่านกล้อง, AI ช่วยวิเคราะห์รูปสินค้า, และซิงค์ข้อมูลผ่าน Google Sheets ได้ทันที

✨ ฟีเจอร์หลัก (Key Features)

📦 จัดการสต็อกสินค้า: เพิ่ม, ลบ, แก้ไขรายการสินค้า, ราคา, และจำนวนสต็อก (รองรับทศนิยม)

📷 สแกนบาร์โค้ด: ใช้กล้องมือถือหรือเว็บแคมสแกนบาร์โค้ดเพื่อค้นหาหรือเพิ่มสินค้าได้ทันที

🤖 AI Image Scan: ใช้ Gemini AI วิเคราะห์รูปภาพสินค้าเพื่อแนะนำชื่อ, หมวดหมู่ และยี่ห้อให้อัตโนมัติ

☁️ Cloud Sync: บันทึกข้อมูลลง Google Sheets อัตโนมัติ ป้องกันข้อมูลสูญหาย และดึงข้อมูลกลับมาได้ทุกเมื่อ

📊 Import/Export: รองรับการนำเข้าและส่งออกข้อมูลเป็นไฟล์ Excel (.xlsx) ตามฟอร์แมตมาตรฐาน

🛡️ Secure Clear Data: ระบบล้างข้อมูลที่มีรหัสยืนยันความปลอดภัย

📱 Responsive Design: ใช้งานได้ดีทั้งบนมือถือ, แท็บเล็ต และคอมพิวเตอร์

🚀 การติดตั้ง (Installation)

โปรเจกต์นี้เป็น Single File Web App ไม่ต้องติดตั้ง Server หรือ Node.js ให้ยุ่งยาก เพียงแค่มีไฟล์ index.html ก็ใช้งานได้เลย

ส่วนที่ 1: การเตรียมไฟล์เว็บไซต์

ดาวน์โหลดไฟล์ index.html จากโปรเจกต์นี้

เปิดไฟล์ index.html ด้วยเว็บเบราว์เซอร์ (แนะนำ Google Chrome หรือ Safari) เพื่อเริ่มใช้งาน

ส่วนที่ 2: การตั้งค่า Google Sheets (สำหรับระบบ Cloud Sync) จำเป็น

เพื่อให้ระบบบันทึกข้อมูลออนไลน์ได้ คุณต้องติดตั้ง Google Apps Script ดังนี้:

ไปที่ Google Apps Script และกด "New Project" (โครงการใหม่)

ลบโค้ดเดิมทั้งหมด และวางโค้ดจากไฟล์ Code.gs ลงไป

กด Save (ตั้งชื่อโครงการว่า StockAPI หรืออะไรก็ได้)

กดปุ่ม "Deploy" (การทำให้ใช้งานได้) > "New deployment" (รายการใหม่)

ตั้งค่าดังนี้:

Select type: Web app

Description: Stock API

Execute as (ดำเนินการในฐานะ): Me (ฉัน)

Who has access (ผู้ที่มีสิทธิ์เข้าถึง): Anyone (ทุกคน) <span style="color:red">(สำคัญมาก! ต้องเลือกข้อนี้เท่านั้น)</span>

กด Deploy และอนุญาตสิทธิ์ (Authorize Access)

คัดลอก Web App URL เก็บไว้ (URL จะลงท้ายด้วย /exec)

📖 คู่มือการใช้งาน (Usage Guide)

1. การตั้งค่าครั้งแรก

กดปุ่ม "ตั้งค่า" (ไอคอนเฟือง) ที่มุมขวาบน

ใส่ Gemini API Key (สำหรับการใช้ AI)

ขอฟรีได้ที่ Google AI Studio

ใส่ Google Sheet App URL ที่ได้จากขั้นตอนการติดตั้งส่วนที่ 2

กดปุ่ม "ตรวจสอบการเชื่อมต่อ" เพื่อยืนยันว่าระบบพร้อมใช้งาน

2. การเพิ่มสินค้า

เพิ่มด้วยมือ: กรอกชื่อ, บาร์โค้ด (ถ้ามี), ราคา, และจำนวนสต็อก แล้วกดบันทึก

สแกนบาร์โค้ด: กดปุ่ม "กล้อง" เพื่อสแกนบาร์โค้ด สินค้าจะถูกค้นหาหรือเตรียมเพิ่มใหม่ทันที

ใช้ AI: กดปุ่ม "AI สแกนรูปภาพ" ถ่ายรูปสินค้า แล้วรอให้ AI ช่วยกรอกข้อมูลให้

3. การดูและแก้ไขสต็อก

กดที่แถบ "รายการสินค้า" ด้านล่าง

คุณจะเห็นรายการสินค้าทั้งหมด สามารถค้นหาได้จากช่องค้นหาด้านบน

การแก้ไข: กดปุ่ม "แก้ไข (รูปดินสอ)" เพื่อปรับปรุงข้อมูลหรือจำนวนสต็อก

การลบ: กดปุ่ม "ถังขยะ" เพื่อลบรายการ

4. การนำเข้า/ส่งออกข้อมูล (Excel)

Export: ไปที่หน้า "รายการสินค้า" กดปุ่ม "Excel" ด้านล่าง เพื่อดาวน์โหลดไฟล์รายงาน

Import: ไปที่หน้า "ตั้งค่า" เลือก "นำเข้า JSON/Excel" เพื่อดึงข้อมูลสินค้าจำนวนมากเข้าสู่ระบบ (ต้องใช้ไฟล์ที่มีหัวตารางตาม Template)

5. การล้างข้อมูล (Clear Data)

ไปที่หน้า "ตั้งค่า" กดปุ่ม "ล้างข้อมูลทั้งหมด"

ระบบจะแสดง รหัสความปลอดภัย 5 หลัก

กรอกรหัสให้ตรงกันเพื่อยืนยันการลบ (ป้องกันการเผลอกด)

🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

Frontend: HTML5, React 18, Tailwind CSS (ผ่าน CDN)

Logic: JavaScript (ES6+ Babel Standalone)

Database (Cloud): Google Sheets via Google Apps Script

Libraries:

html5-qrcode: สำหรับสแกนบาร์โค้ด

xlsx (SheetJS): สำหรับจัดการไฟล์ Excel

⚠️ หมายเหตุ

ข้อมูลในเครื่องจะถูกเก็บไว้ใน LocalStorage ของเบราว์เซอร์

การเชื่อมต่อ Google Sheets จะทำงานแบบ Auto-Sync เมื่อมีการแก้ไขข้อมูล ระบบจะบันทึกขึ้น Cloud ทันที
